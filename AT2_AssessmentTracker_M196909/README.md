# Assessment Tracker

**Student:** John Richardson (M196909)

A WPF application (C#, .NET 9) that tracks assessments: unit/cluster, assessment name, type, due date
(MM-dd-yyyy) and grade (NYM, NYS or S). Assessments graded S move to a separate Completed list.
Data loads from and saves to `Unitinfo.txt` and `Completedinfo.txt`, and saves automatically on close.
